# Language Policy

All content in this repository MUST be written in **English (en_US)**.

## Rules

- Every file — documentation, comments, commit messages, PR descriptions, issue templates, skill descriptions, prompt metadata, and code comments — must use American English (en_US).
- Do not write in Portuguese, Spanish, or any other language.
- Book titles and proper nouns may remain in their original language (e.g., "Engenharia de Prompts II" as a citation), but all surrounding documentation must be in English.
- When translating or adapting content from non-English sources, always produce the final output in en_US.

## Rationale

This repository is intended for international consumption. A single language standard ensures consistency, reduces confusion, and makes the project accessible to the widest possible audience.
